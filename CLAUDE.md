## Project Overview

Static website for DMC Industries PNW LLC, a defense drone manufacturing company. Hosted on GitHub Pages with custom domain (dmcindustriespnw.com).

## Development

No build system or dependencies. Open HTML files directly in a browser to preview.

```bash
open index.html
```

## Structure

- `index.html` - Main landing page (GitHub Pages entry point)
- `static/` - Alternative landing page variants
- `CNAME` - Custom domain configuration for GitHub Pages

## Design System

CSS variables defined in `:root`:
- `--gold: #F5A623` (primary accent)
- `--navy-deep: #0d1419` (background)
- `--white: #f0f4f7` (text)

Fonts: Orbitron (headings), Source Sans 3 (body) via Google Fonts.
